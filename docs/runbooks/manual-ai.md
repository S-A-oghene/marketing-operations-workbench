# Manual AI Bridge runbook

1. Create a recipe.
2. Confirm data class.
3. Generate prompt package.
4. Copy package.
5. Open the external AI site yourself.
6. Run the prompt yourself.
7. Copy result.
8. Paste result into Workbench.
9. Parse and run deterministic QA.
10. Optionally evaluate with Kev.
11. Human review and approve.
12. Save provenance.

Never use DOM scraping, cookie extraction, hidden automation, synthetic clicks or anti-bot bypass.
