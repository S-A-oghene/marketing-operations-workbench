# MOW/AOG Architecture Constitution

1. The Workbench is the system of record.
2. External platforms are execution and observation edges.
3. AI providers are replaceable accelerators.
4. Core workflows must work without AI.
5. Manual browser AI is a supported execution mode.
6. Human review controls publication, outreach, and other consequential actions.
7. Measured facts, generated content, human decisions, and AI suggestions remain distinct.
8. Unknown evidence is `UNKNOWN` or `NOT_AVAILABLE`; it is never coerced to zero/false.
9. No fabricated metrics, contacts, employment history, clients, spend, outcomes, or platform permissions.
10. Restricted data never leaves the approved security boundary.
11. Provider SDKs never enter Core.
12. Connector readiness requires capability evidence.
13. A sent API request is not publication evidence.
14. A backup is not validated until restore has been exercised.
15. Any stop condition blocks release progression.
